# UI Skills

Repo-local UI skills. Before making a front-end change, check whether one of
these already covers it and follow it instead of rediscovering the approach.

- [heroContentHWResponsviness](heroContentHWResponsviness.md) — make the hero's
  featured media (the hand image) fit inside the first viewport on every
  screen size and never overflow into the section beneath it. Covers
  viewport-budget sizing (`100svh` minus the chrome above), in-flow vs
  absolutely-positioned fixes, the `?v=N` cache-buster bump, and the
  headless-Chrome viewport matrix used to verify.
